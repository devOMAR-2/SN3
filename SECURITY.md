# Security Policy

## Supported versions
SN3 is **pre-release** and has no supported production version yet. This policy will be updated before the first public release.

## Reporting vulnerabilities
**Do not disclose exploitable details in public GitHub Issues or Discussions.**

If GitHub **Private vulnerability reporting** is enabled, use the repository's **Security → Report a vulnerability** workflow. If unavailable, contact a maintainer privately through their GitHub profile and request a secure reporting channel; do not send credentials or sensitive data through public comments.

Please include a description, affected component, reproducible steps (without live secrets), impact, and a suggested fix if known.

## Handling
Maintainers will acknowledge reports as capacity allows, assess impact, coordinate remediation, and publish an advisory when appropriate. No guaranteed response or fix timeframe is promised.

## Scope of particular concern
Team/tenant isolation, private project access, invitation tokens, attachment authorization, GitHub App installation permissions, webhook signature verification, secret handling, and self-hosted configuration.
